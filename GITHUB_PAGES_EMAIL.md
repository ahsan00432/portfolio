# GitHub Pages Gmail Setup

The portfolio uses [FormSubmit](https://formsubmit.co/) when hosted at:

```text
https://ahsan00432.github.io/portfolio/
```

Form submissions are sent to `a3216572@gmail.com`.

## Activate Gmail delivery

1. Submit the contact form once from the live GitHub Pages site.
2. Open the activation email sent by FormSubmit to `a3216572@gmail.com`.
3. Confirm the email address.
4. Future submissions will be delivered automatically.

The activation email is only required for the first submission.

## Deploy

Commit and push the changes. GitHub Pages will serve the updated static site from the repository.
