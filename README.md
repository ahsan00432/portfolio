# Ahsan's Portfolio

This is a static HTML, CSS, and JavaScript site. To publish it on Cloudflare Pages, connect this repository as a **Pages** project, leave the build command empty, and set the output directory to `.`. Do not deploy it as a Worker with `wrangler deploy`.

The contact form sends messages to `a3216572@gmail.com` through FormSubmit. After the first live submission, confirm the activation email sent by FormSubmit. No server, build step, or API key is required.
